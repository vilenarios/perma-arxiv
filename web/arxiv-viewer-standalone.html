Welcome to the ArXiv Paper Archive

This is a standalone viewer for ArXiv papers stored in Parquet format.

⚠️ Standalone Version

This version works without external dependencies but has limitations:

  • Parquet files must be converted to JSON format first
  • Limited to smaller datasets (under 50MB)
  • Basic search and filter functionality

For full functionality with native Parquet support, use the CDN version.

To get started:

  1. Export your Parquet to JSON format
  2. Load the JSON file using the button above
  3. Or enter an Arweave transaction ID
