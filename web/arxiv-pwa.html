Smart Loading Strategies

Choose how you want to access the ArXiv archive. Each strategy optimizes for different use cases:

📋 Metadata Only

~5 MB
Quick browsing of titles, authors, and dates. Perfect for mobile or slow connections.
  • ✅ Instant loading
  • ✅ Offline capable
  • ❌ No full abstracts

📅 Recent Papers

~20 MB
Last 3 months of papers with full details. Great for staying current.
  • ✅ Full abstracts
  • ✅ Latest research
  • ❌ No historical data

🏷️ By Category

~30-50 MB each
Load only the categories you care about. Efficient for specialized research.
  • ✅ Complete category data
  • ✅ Selective download
  • ✅ Mix and match

🌊 Streaming Mode

As needed
Load data on-demand using HTTP range requests. No upfront download.
  • ✅ No initial download
  • ✅ Access everything
  • ❌ Requires connection
